# 📊 Prometheus, Node Exporter, and Grafana Stack

This repository provides a simple setup using **Docker Compose** to deploy:
- **Prometheus** (metrics collection)
- **Node Exporter** (node metrics)
- **Grafana** (visualization)

---

## 📂 Directory Structure

```bash
├── node-exporter/
│   └── docker-compose.yml
├── prometheus-grafana/
│   └── docker-compose.yml
├── prometheus.yml
└── README.md
```
